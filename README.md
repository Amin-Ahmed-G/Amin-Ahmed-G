> **Comprehensive 42-Hour Industrial PLC Curriculum & Capstone Project**
- Full 6-module curriculum covering PLC hardware, scan cycle, timers, counters, analog signal scaling, PID control, VFD integration, and HMI design.
- Includes **genuine CODESYS binary project files (`.project`)**, Structured Text (`.st`) code examples, PowerPoint presentation decks, training guides, and a complete capstone Conveyor Belt Sorting System with commissioning test sheets.
- **Key Modules**:
  - `Day 1`: Hardware architecture, scan cycle mechanics, NO/NC fail-safe wiring, Motor Seal-In & Forward/Reverse interlock
  - `Day 2`: TON/TOF/RTO timers, CTU/CTD counters, R_TRIG scan-level proof, 3-phase Traffic Light state machine
  - `Day 3`: 4–20mA scaling formula derivation, 2°C hysteresis dead-band, 3-sample FIFO moving average filter, circular buffer event log
  - `Day 4`: Structured variables (STRUCT), FOR/WHILE ST loops, 8-step batch sequencer, 10-zone conveyor shift register
  - `Day 5`: HMI tag binding, 3-tier alarm severity management, VFD parameter setup, closed-loop PID pump level control
  - `Day 6`: Capstone Conveyor Sorting System with pneumatic divert arm, VFD speed reference, E-stop safety latch, and commissioning checklist
